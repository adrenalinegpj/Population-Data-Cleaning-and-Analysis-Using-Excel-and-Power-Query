# Population Data Cleaning & Analysis

## Project Overview

This project focuses on cleaning, transforming, and analyzing population data using **Python**.

The main goal was to prepare raw population data for reliable analysis by handling missing values, correcting inconsistent data, standardizing formats, and creating useful analytical columns.

## Data Cleaning

The dataset was cleaned using Python and Pandas. The following steps were performed:

- Removed unnecessary and empty rows.
- Handled missing and invalid values.
- Removed extra spaces from text columns.
- Standardized text formatting.
- Cleaned and standardized gender values.
- Cleaned phone number formats by removing unwanted characters.
- Converted and validated numerical fields such as age.
- Created additional columns for analysis.
- Checked the consistency and quality of the cleaned dataset.

## Analysis

The cleaned dataset was used to analyze:

- Population distribution by country and city.
- Male and female population percentages.
- Population distribution by year.
- Accommodation types.
- Total population and related indicators.
